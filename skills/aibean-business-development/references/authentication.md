# 临时 AiBean API 认证

## 适用范围

流程元数据查询、流程表/默认表单绑定、菜单读取/保存以及其他在线 AiBean API 都要求认证。Server API 的 `/api` 与 Biz API 代理的 `/bapi` 共用同一个令牌。这个要求只影响智能体在开发过程中调用运行中的 API；最终 Vue 页面仍通过项目既有请求封装和用户自己的登录态访问 API。

## 获取与保存

1. 先检查当前智能体会话是否已经具有可用的 AiBean API 认证上下文。
2. 没有时，提示用户通过安全输入功能输入当前登录会话的 `Authorization` 值，格式为 `Bearer <access-token>`。优先使用不回显、不写入聊天记录和 shell 历史的秘密输入；不要要求用户修改业务源码或配置文件。
3. 仅在当前会话的内存或临时、进程作用域内保存该值。需要环境变量时使用专用名称 `AIBEAN_API_AUTHORIZATION`，并且禁止打印、记录、提交或持久化它。
4. 发起 HTTP 请求时将该值原样放入 `Authorization` 请求头。不要把令牌拼接到 URL、查询参数、日志、异常信息或测试夹具中。

## 失败处理

- 遇到 401 或 403，立即停止所有在线 AiBean API 调用，提示用户重新登录并输入新的临时令牌。
- 不反复重试、探测其他认证方式、使用硬编码默认账号，或在 `/api` 与 `/bapi` 之间切换以规避认证失败。
- 用户不提供令牌时，继续完成不依赖在线 API 的本地源码分析与代码编写；将需要在线查询或写入的步骤列为未执行项。
